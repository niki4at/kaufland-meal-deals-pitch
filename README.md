# Kaufland Bulgaria · Meal Deal pitch deck

A self-contained HTML slide deck (14 slides, 16:9) proposing a fixed-price meal deal
(ToGo vitrina main + bakery item + drink) for Kaufland Bulgaria, tailored to
Stephan Lüger, Commercial Director and Management Board member.

## Run it

Open `index.html` in any browser. No build step, no server.

- Navigate: `←` `→` arrow keys, `Space`, `PageUp`/`PageDown`, `Home`/`End`, or the on-screen arrows
- Charts render via Chart.js 4.4.7 (CDN); Inter font via Google Fonts (CDN). Internet required on first load.

## Structure

1. Title
2. Executive summary
3. Market context (Lidl overtook Kaufland in FY2024)
4. The untapped lunch mission and Kaufland's three existing assets
5. The mechanic and price architecture (€4.49 / €3.99 XTRA)
6. Six launch combinations with real reference prices
7. Evidence base (UK meal deal benchmarks)
8. Unit economics (33% margin per deal)
9. Financial projections (3 scenarios, cannibalisation modelled)
10. Halo effects (frequency, data, waste)
11. SAP integration architecture (S/4HANA Bonus Buy → GK POS → CAR → XTRA)
12. 8-week build plan
13. 12-week pilot with KPI gates
14. The ask
